# Переписка для 1С:УНФ — демонстрация

Самостоятельный статический сайт с интерфейсом корпоративной переписки. Демонстрационные сообщения, контакты, заказы и задачи хранятся только в браузере. Сайт не подключён к настоящим MAX, 1С или серверу, не отправляет реальные сообщения и не создаёт реальные документы.

## Запуск

Нужен Python 3.11 или новее; библиотек устанавливать не требуется. В папке проекта выполните:

```sh
python -m http.server 8080 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:8080/`.

Можно переключать чаты, создавать тестовые диалоги, отправлять сообщения в демонстрационную историю, прикреплять файлы до 500 КБ, создавать тестовые заказы и задачи. Кнопка «Управление демо» показывает входящие сообщения, приостановку подписки и сброс данных. Голосовые пока показаны как пример; реальное подключение требует отдельной реализации и проверки.

## Состав

- `index.html` — интерфейс и политика безопасности.
- `app.js` — сценарии демонстрации и локальное хранение данных.

Для настоящего подключения потребуется отдельный сервер, авторизация, тарифы, адаптер MAX и расширение 1С. Секреты доступа нельзя помещать в этот репозиторий или в клиентский JavaScript.
